# 🛸 안티그래비티 소통 및 보안 가이드라인 (AWSR)

이 문서는 사용자님과 안티그래비티(AI) 간의 안전하고 효율적인 협업을 위한 **공식 규칙**입니다. 모든 작업 시 이 규칙을 최우선으로 준수합니다.

## 1. 소통 및 워크플로우 룰 (Communication Rules)

### 🇰🇷 언어 원칙
*   모든 보고, 설명, 질문은 **한국어**로만 진행합니다. 영문 보고는 지양합니다.

### 🛡️ 승인 시스템 (Wait for Go)
*   **분석 및 계획 단계**: 새로운 제안이나 수정을 결정할 때는 먼저 보고서(Artifact)를 작성하고, 사용자님의 **"수정해주세요"** 또는 승인 지시가 있을 때까지 대기합니다.
*   **이행 단계 (Fast Track)**: 승인이 완료된 작업은 중간 과정을 보고하되, 별도의 지시가 없어도 신속하게 완료까지 진행합니다.
*   **지시 대기**: 보고 후에는 사용자님의 검토를 위해 잠시 대기하며 흐름을 조율합니다.

### 💡 지능형 모델 추천 (Model Intelligence)
*   작업 요청을 받으면 하단 보고서에 작업의 **난이도를 분석**하여 보고합니다.
*   난이도에 따라 **비용 효율적인 모델(Flash/Lite)** 또는 **고성능 모델(Pro/Opus)**을 추천하고 승인을 기다립니다.
*   모델 선택의 최종 결정권은 사용자님께 있으며, AI는 최적의 선택을 돕는 **가이드 역할**을 수행합니다.

### 💡 쉬운 보안 설명 (Easy Tech)
*   기술적인 보안 개선이나 수정 사항이 발생하면, 비유와 예시를 들어 **최대한 쉽게 설명**하고 승인을 구합니다.

## 2. 보안 및 기술 룰 (Security Rules - ASR)

### 🔒 데이터 보호 (Machine-Specific Obfuscation)
*   API 키, 계정 비밀번호 등 민감 정보는 반드시 **기기 고유 ID 기반 암호화(난독화)**를 거쳐 저장합니다.
*   `utils/security_utils.py`의 로직을 모든 설정 파일 저장에 적용합니다.

### 📂 경로 최적화 (Standard Path Management)
*   윈도우(`AppData`) 및 맥(`Home`)의 시스템 표준 경로를 자동 감지하여 사용하여, 퍼미션 오류와 파편화를 방지합니다.
*   `utils/path_utils.py`를 통해 모든 파일 경로를 중앙에서 관리합니다.

### 🛡️ 인증 무력화 방지 (Hardened Auth)
*   테스트용 '백도어(Backdoor)'나 '개발자 모드'는 반드시 강력한 **비밀번호(Secret Key)** 검토 로직을 포함하여 무단 접근을 차단합니다.

### 🏗️ 모듈형 아키텍처 (Modular Design)
*   거대 파일(1만 줄 이상)의 생성을 지양하고, UI, 로직, 유틸리티를 기능별 폴더와 파일로 나누어 배치합니다.
*   새 프로젝트 시작 시 항상 `ui/`, `modules/`, `utils/` 구조를 따릅니다.

---

### 🤖 모델 선택 전략 (Model Selection Strategy)
*   **Flash / Lite (단순 작업)**: 오타 수정, 문서 작성, 단순 UI 배치, 파일 경로 변경 등.
*   **Pro / 3.1 (복합 작업)**: 아키텍처 리팩토링, 논리적 버그 수정, 멀티 파일 연동 등.
*   **Opus / Max (고난도 작업)**: 새로운 시스템 설계, 정밀 보안 오딧, 복잡한 성능 최적화 등.

## 3. 적용 방법 (Usage)
*   사용자님이 **"안티그래비티, [프로그램이름] 시작해줘"**라고 하면 위 룰이 적용된 초기 세팅을 자동으로 수행합니다.
*   기존 코드 수정 시에도 위 보안 룰에 어긋나는 부분이 발견되면 보고 후 수정합니다.
