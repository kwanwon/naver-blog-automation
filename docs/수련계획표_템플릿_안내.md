# 📊 수련계획표 스프레드시트 설정 가이드

## 🔗 템플릿 생성 방법

### 1단계: 새 스프레드시트 생성
1. [Google 스프레드시트](https://sheets.google.com) 접속
2. **+ 새 스프레드시트** 클릭

### 2단계: 열 구조 설정

첫 번째 행(헤더)에 다음을 입력하세요:

| A1 | B1 | C1 | D1 | E1 | F1 |
|---|---|---|---|---|---|
| 날짜 | 요일 | 수련내용 | 오전 | 오후 | 저녁 |

### 3단계: 날짜 데이터 입력

| 날짜 | 요일 | 수련내용 | 오전 | 오후 | 저녁 |
|------|-----|---------|-----|-----|-----|
| 2026-01-16 | 목 | (행사명 또는 공란) | 챔피온1250 | 성장스트레칭, 체력측정 | (공란) |
| 2026-01-17 | 금 | 대통령배대회 | 호신술, 시범, 낙법 | 대련예선전 | 휴식 및 단합 |

## 📋 열 설명

| 열 | 설명 | 예시 |
|---|---|---|
| **A (날짜)** | YYYY-MM-DD 형식 | 2026-01-16 |
| **B (요일)** | 요일 | 목, 금, 토... |
| **C (수련내용)** | 행사명 또는 공통 내용 | 대통령배대회, 승급심사 |
| **D (오전)** | 오전 시간대 수련내용 | 챔피온1250 |
| **E (오후)** | 오후 시간대 수련내용 | 성장스트레칭, 체력측정 |
| **F (저녁)** | 저녁 시간대 수련내용 | 휴식 및 단합 |

## 🔗 폴더-시간대 매핑

| 시간대 | 해당 폴더 |
|--------|----------|
| **오전** | 생활체육오전반, 캠프활동 |
| **오후** | 1시부~6시부, 승급심사, 승단심사, 대회 |
| **저녁** | 7시부~9시부, 선수부, 시범부, 합숙훈련 |

## 🔄 콘텐츠 결합 규칙

1. **C열 + 시간대열** 모두 있으면 → 결합 (예: "대통령배대회 호신술, 시범")
2. **C열만** 있으면 → C열만 사용
3. **시간대열만** 있으면 → 시간대열만 사용
4. **둘 다 공란**이면 → 다른 시간대에서 폴백

## 🔒 공유 설정 (필수!)

1. **공유 버튼** 클릭 (오른쪽 상단)
2. **일반 액세스** → "링크가 있는 모든 사용자"
3. **역할** → "뷰어"
4. **링크 복사** → 앱에 붙여넣기

## ❓ 자주 묻는 질문

### Q: 시간대별 열을 안 만들어도 되나요?
A: 네! 기존처럼 C열(수련내용)만 사용해도 됩니다. 시간대별 열은 선택사항입니다.

### Q: 특정 시간대가 공란이면?
A: 다른 시간대에서 자동으로 가져옵니다. (폴백 로직)

### Q: 날짜 형식은?
A: `2026-01-16` 또는 `2026/01/16` 모두 지원됩니다.
