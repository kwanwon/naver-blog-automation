🔑 Google Gemini API 키 3분 발급 가이드

구글 계정만 있으면 비용 0원(완전 무료)으로 하루 수천 건의 AI 글을 생성할 수 있습니다.

Google AI Studio 바로가기 ↗
1

Google AI Studio 사이트 접속 및 로그인

위 초록색 버튼이나 aistudio.google.com/app/apikey 에 접속한 뒤, 보유 중인 구글 계정으로 로그인합니다.

2

[Create API key] 파란색 버튼 클릭

화면 우측 상단 또는 중앙에 보이는 파란색 [Create API key] 버튼을 누릅니다.

💡 프로젝트를 선택하라는 팝업이 뜨면 [Create API key in new project] (새 프로젝트에서 키 생성)를 선택하세요.
3

발급된 API 키 복사 (Copy)

잠시 후 AIzaSy... 로 시작하는 영어+숫자 조합의 고유 키가 생성됩니다. [Copy] 버튼을 눌러 복사합니다.

4

프로그램 [설정] 탭에 붙여넣기 및 저장

라이온 프로그램 실행 후 [설정] 탭 > [AI 설정] > [Gemini API Key] 입력란에 복사한 키를 붙여넣고 [설정 저장]을 누르면 끝입니다!

🛡️ 비용 걱정 전혀 없습니다: 구글 AI 스튜디오는 Free Tier(무료 등급)로 매일 수백~수천 회를 무료로 제공하므로 신용카드 등록 없이 안심하고 쓰실 수 있습니다.

💻 설치 및 최초 실행 안내

OS 보안 경고창이 뜰 때의 해결 방법입니다.

🪟 Windows SmartScreen 경고 시

마이크로소프트 공식 인증서 등록 전 배포 파일이므로 "Windows의 PC 보호" 푸른색 창이 나타날 수 있습니다.

1 창 왼쪽 상단의 [추가 정보] 텍스트를 클릭합니다.
2 하단에 나타나는 [실행] 버튼을 클릭하면 정상 실행됩니다.
🍎 macOS 보안 경고(확인되지 않은 개발자) 시

인터넷에서 다운로드한 앱이므로 "악성 소프트웨어가 있는지 확인할 수 없습니다" 경고가 뜰 수 있습니다.

1 앱 아이콘을 마우스 우클릭(또는 Control + 클릭) > [열기]를 누릅니다.
2 팝업창에서 다시 [열기]를 누르면 이후로는 클릭만으로 실행됩니다.

❓ 자주 묻는 질문 (FAQ)

Q. 시리얼 인증 번호는 어디서 받나요?

프로그램 사용권 및 시리얼 번호는 관리자에게 직접 문의하여 발급받으실 수 있습니다. 발급받으신 영문+숫자 시리얼 키를 첫 화면에 입력하시면 즉시 정품 인증이 완료됩니다.

Q. 프로그램 업데이트는 어떻게 진행되나요?

새로운 기능이나 패치가 출시되면 프로그램 우측 상단에 [업데이트] 버튼이 표시됩니다. 버튼을 1번만 클릭하시면 다운로드부터 최신 버전 재실행까지 자동으로 완료되며, 기존 설정과 시리얼 정보는 100% 안전하게 유지됩니다.

Q. 네이버 아이디 로그인 보안에 문제는 없나요?

라이온 마케팅 프로그램은 외부 서버로 아이디나 비밀번호를 절대 전송하지 않습니다. 관장님의 PC 로컬 크롬 브라우저 환경에서 직접 제어되므로 안전합니다.
