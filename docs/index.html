Google AI Studio 바로가기 ↗
1

Google AI Studio 사이트 접속 및 로그인

위 초록색 버튼이나 aistudio.google.com/app/apikey 에 접속한 뒤, 보유 중인 구글 계정으로 로그인합니다.

2

[Create API key] 파란색 버튼 클릭

화면에 보이는 파란색 [Create API key] 버튼을 누릅니다.

💡 프로젝트를 선택하라는 팝업이 뜨면 [Create API key in new project] (새 프로젝트에서 키 생성)를 선택하세요.
3

발급된 API 키 복사 (Copy)

잠시 후 생성되는 AIzaSy... 로 시작하는 고유 키를 [Copy] 버튼을 눌러 복사합니다.

4

프로그램 [설정] 탭에 붙여넣고 저장

프로그램 실행 후 [설정] 탭 > [AI 설정] > [Gemini API Key] 란에 붙여넣고 [설정 저장]을 누르면 완료됩니다.

🛡️ 비용 걱정 전혀 없습니다: 구글 AI 스튜디오는 Free Tier(무료 등급)로 매일 수천 건 생성을 무료로 제공하므로 신용카드 등록 없이 안심하고 쓰실 수 있습니다.

  • 🔄 업데이트 확인 버튼 새 패치가 나오면 원클릭으로 100% 안전하게 최신 버전으로 교체 재시작됩니다.
☁️

1. [날씨/뉴스] 탭 - 지역 감성 인트로 글 작성

실시간 기상청 날씨 및 미세먼지 정보를 연동한 오프닝 글 생성

• 지역 설정: 체육관이 위치한 시/군/구를 설정해두면 오늘 실시간 기온, 하늘 상태(맑음/비/눈), 미세먼지 수치를 자동으로 불러옵니다.

• 오늘의 한 줄 추천: "쌀쌀해진 환절기, 우리 아이들 면역력을 높이는 수련 이야기"와 같이 날씨에 딱 맞는 서론 문구를 AI가 알아서 블로그 첫머리에 구성해 줍니다.

📝

2. [블로그 포스팅] 탭 - 네이버 블로그 완전 자동 발행

수련 사진 지정 → AI 맞춤 본문 작성 → 네이버 스마트에디터 자동 발행

Step 1. 종목 & 주제 선택 합기도, 태권도, 주짓수, 줄넘기 등 체육관 종목을 고르고 오늘 수련한 주제를 선택합니다.
Step 2. 사진 폴더 연결 오늘 찍은 수련생 사진들이 들어있는 폴더를 [폴더 선택] 버튼으로 지정합니다.
Step 3. 즉시/예약 발행 [AI 글생성 및 포스팅]을 누르면 크롬 브라우저가 자동으로 열려 글과 사진을 깔끔하게 올립니다.
👥

3. [밴드 마케팅] 탭 - 실시간 사진 감지 자동 포스팅

체육관 밴드 학부모 소통을 100% 무인으로 처리하는 핵심 기능

• 실시간 폴더 감지 모드: 스마트폰으로 찍은 사진이 구글 드라이브나 지정 폴더에 들어오는 순간, 프로그램이 이를 감지하여 AI 글 작성 후 밴드에 즉시 게시합니다.

• 사진/동영상 지능형 분할: 동영상이 많을 경우 네이버 밴드 제한에 걸리지 않도록 10개 단위로 자동 분할하며, 피드 맨 위에는 메인 수련 이야기와 사진이 오도록 완벽한 순서로 포스팅합니다.

⚙️

4. [설정] 탭 - 체육관 프로필 & AI 맞춤 지침 등록

체육관 기본 정보, 네이버 로그인 계정, AI 성격 맞춤 설정

• Gemini API Key: 구글 AI 스튜디오에서 발급받은 무료 키를 여기에 저장합니다.

• 체육관 기본 정보: 도장 이름, 대표 번호, 블로그 주소, 밴드 주소를 한 번만 입력해 두면 모든 포스팅에 자동으로 들어갑니다.

• AI 사용자 지침 (Prompt): 관장님만의 특별한 관훈이나 어투를 자유롭게 입력할 수 있습니다. (아래 4번 섹션 참고)

💡 AI 맞춤 지침(프롬프트) 설정법 & 실전 예시

라이온 프로그램에는 이미 수준 높은 체육관 전문 AI 지침이 기본 내장되어 있어 아무것도 입력하지 않으셔도 훌륭한 글이 작성됩니다.
하지만 "우리 도장만의 특별한 철학이나 말투"를 원하신다면 아래 예시를 복사해 [설정] 탭의 [AI 지침] 칸에 넣어보세요!

🥋

예시 1. 인성 교육 & 예절 중심 도장 (태권도 / 합기도 / 검도)

부모님께 예의 바르고 배려심 넘치는 아이로 키우는 따뜻한 신뢰 중심 어조

[체육관 AI 작성 지침] 1. 어조: 사범님이 학부모님께 직접 도장 하루를 들려주듯 다정하고 정중한 어조 (~했답니다, ~응원해 주세요). 2. 강조 포인트: 단순한 신체 단련뿐만 아니라 신발 정리, 친구에 대한 양보, 큰 소리로 인사하기 등 '인성 교육'의 중요성을 본문에 자연스럽게 1단락 포함할 것. 3. 필수 마무리 문구: "수련을 마치고 집에 돌아간 우리 아이에게 아낌없는 칭찬과 따뜻한 포옹을 꼭 건네주세요!" 4. 해시태그 필수 포함: #인성교육 #예절교육 #자신감향상 #초등체육 #바른아이
🥊

예시 2. 실전 호신술 & 체력 단련 중심 (주짓수 / 복싱 / 킥복싱 / MMA)

땀 흘리는 열정과 자기방어 능력을 강조하는 에너지 넘치는 어조

[체육관 AI 작성 지침] 1. 어조: 활기차고 에너지 넘치며 전문 트레이너의 열정이 느껴지는 파워풀한 어조 (~합니다! 파이팅!). 2. 강조 포인트: 일상 속 스트레스 해소, 기초 체력 향상, 위급 상황에서 내 몸을 지키는 실전 호신술 기술의 원리를 쉽게 설명할 것. 3. 안심 문구: "초보자나 여성분들도 부상 걱정 없이 본인의 체력에 맞춰 안전하고 즐겁게 훈련할 수 있습니다." 4. 해시태그 필수 포함: #실전호신술 #자기방어 #체력단련 #스트레스해소 #다이어트운동
🌱

예시 3. 유치부 & 초등 저학년 성장 발달 (키즈반 / 유아체육 / 줄넘기)

엄마들의 마음에 공감하는 사랑스럽고 밝은 유아체육 어조

[체육관 AI 작성 지침] 1. 어조: 아이들을 진심으로 아끼는 이모, 삼촌 사범님처럼 사랑스럽고 밝은 어조 (적절한 이모티콘 🌟💪 사용). 2. 강조 포인트: 성장판을 자극하는 점프 운동, 소근육/대근육 발달, 스마트폰을 내려놓고 친구들과 땀 흘리며 뛰노는 사회성 발달 강조. 3. 부모 공감 문구: "처음에는 낯설어하던 아이들도 도장에만 오면 웃음꽃이 활짝 핍니다. 안전을 최우선으로 세심하게 케어합니다." 4. 해시태그 필수 포함: #키성장운동 #성장판자극 #유아체육 #키즈운동 #면역력강화

💻 설치 및 최초 실행 안내

OS 보안 경고창이 뜰 때의 10초 해결 방법입니다.

🪟 Windows SmartScreen 경고 시

마이크로소프트 공식 인증서 등록 전 배포 파일이므로 "Windows의 PC 보호" 푸른색 창이 나타날 수 있습니다.

1 창 왼쪽 상단의 [추가 정보] 텍스트를 클릭합니다.
2 하단에 나타나는 [실행] 버튼을 클릭하면 정상 실행됩니다.
🍎 macOS 보안 경고(확인되지 않은 개발자) 시

인터넷에서 다운로드한 앱이므로 "악성 소프트웨어가 있는지 확인할 수 없습니다" 경고가 뜰 수 있습니다.

1 앱 아이콘을 마우스 우클릭(또는 Control + 클릭) > [열기]를 누릅니다.
2 팝업창에서 다시 [열기]를 누르면 이후로는 클릭만으로 실행됩니다.

❓ 자주 묻는 질문 (FAQ)

Q. 시리얼 인증 번호는 어디서 받나요?

프로그램 사용권 및 시리얼 번호는 관리자에게 직접 문의하여 발급받으실 수 있습니다. 발급받으신 시리얼 키를 첫 화면에 입력하시면 즉시 정품 인증이 완료됩니다.

Q. 프로그램 업데이트는 어떻게 진행되나요?

새로운 기능이나 패치가 출시되면 프로그램 우측 상단에 [업데이트 확인] 버튼이 표시됩니다. 클릭 1번으로 최신 버전 다운로드와 재실행이 완료되며, 기존 설정과 시리얼 정보는 100% 안전하게 유지됩니다.

Q. 네이버 아이디 로그인 보안에 문제는 없나요?

라이온 마케팅 프로그램은 외부 서버로 아이디나 비밀번호를 절대 전송하지 않습니다. 관장님의 PC 로컬 크롬 브라우저 환경에서 직접 안전하게 실행됩니다.
