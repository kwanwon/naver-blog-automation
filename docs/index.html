📂 2. 어디 폴더에 넣나요? OS별(윈도우 vs 맥) 실제 경로 비교

수동으로 사진을 넣거나 구글 드라이브 동기화 폴더를 지정할 때 아래 경로를 그대로 사용하시면 됩니다.

🪟

Windows (윈도우) 경로 안내

탐색기(내 PC)에서 확인 가능한 실제 위치

① 프로그램 공식 전용 데이터 폴더 (자동 생성)
내 PC > 문서 > 블로그자동화_데이터 > 블로그_카페_수동이미지

실제 절대 경로: C:\Users\<내계정명>\Documents\블로그자동화_데이터

② 기본 다운로드(Downloads) 폴더
내 PC > 다운로드 (Downloads)

실제 절대 경로: C:\Users\<내계정명>\Downloads

③ 구글 드라이브 데스크톱 연동 시 (추천)
내 PC > Google Drive (G: 드라이브) > 내 드라이브 > 수련사진

스마트폰에서 구글 드라이브로 올리면 윈도우 G: 드라이브로 즉시 동기화됩니다.

🍎

macOS (맥) 경로 안내

Finder(파인더)에서 확인 가능한 실제 위치

① 프로그램 공식 전용 데이터 폴더 (자동 생성)
Finder > 문서 > 블로그자동화_데이터 > 블로그_카페_수동이미지

실제 절대 경로: /Users/<내계정명>/Documents/블로그자동화_데이터

② 기본 다운로드(Downloads) 폴더
Finder > 다운로드 (Downloads)

실제 절대 경로: /Users/<내계정명>/Downloads

③ 구글 드라이브 연동 시 (추천)
Finder > 위치 > Google Drive > 내 드라이브 > 수련사진

맥용 Google Drive 앱이 실행되어 있으면 Finder 사이드바에 즉시 표시됩니다.

⚙️ 3. 이미지 폴더를 만들어 사진을 넣으면 어떻게 작동하나요?

관장님이 20261029_낙법수련 또는 3시부 폴더를 만들고 사진 10장을 넣었을 때 프로그램 내부에서 일어나는 5단계 프로세스입니다.

1 폴더 생성 및 복사

지정 경로에 날짜나 부서명으로 폴더를 만들고 사진을 넣습니다.

파일명 자동 인식
2 순서 정렬 & 무결성

파일명 순서나 촬영 시간순으로 정렬하며 깨진 파일은 자동 제외합니다.

시간순 자동 정렬
3 EXIF 정리 & GPS

스마트폰 불필요 메타데이터를 정리하고 체육관 위치 GPS를 최적 주입합니다.

노출 최적화
4 문맥 사이 자동 삽입

AI가 작성한 본문 서론, 본론, 결론 단락 사이에 1~2장씩 번갈아가며 자동 배치합니다.

스마트에디터 발행
5 백업 폴더 자동 이동

발행 성공 시 원본 사진을 백업 폴더로 옮겨 중복 사용을 100% 방지합니다.

중복 재발행 방지

🤖 4. 감지모드(Watch Mode) 완전 정복 - 블로그, 밴드, 카페

감지모드란? 프로그램을 켜두기만 하면, 관장님이 스마트폰으로 구글 드라이브나 감시 폴더에 사진/영상을 넣는 순간 마우스 조작 없이 스스로 글을 쓰고 발행하는 100% 무인 자동화 모드입니다.

👥 네이버 밴드 감지모드

• 작동 흐름: 스마트폰으로 구글 드라이브(예: 3시부)에 사진/영상 업로드 > 60초 디바운스 대기(파일 전송 완료 확인) > AI 글 작성 > 동영상 분할 업로드 > 본문+사진 피드 최상단 발행 > 백업 이동.
• 특징: 매일 학부모님께 수련 현장을 생생하게 공유하는 데 가장 최적화되어 있습니다.

📝 네이버 블로그 감지모드

• 작동 흐름: 블로그 지정 감시 폴더에 사진 감지 > 구글 시트 주제 또는 로컬 주제 풀 반영 > Gemini 3.1 AI 글 작성 > 스마트에디터 ONE 자동 업로드 > 태그/플레이스 삽입 > 발행 완료.
• 주의사항: 동영상은 제외되며 오직 사진(이미지)만 처리됩니다.

☕ 네이버 카페 감지모드

• 작동 흐름: 카페 지정 감시 폴더에 사진 감지 > 도장 로고 워터마크 자동 합성 > 카페 지정 게시판 선택 > 본문 작성 및 사진 등록 > 완료.
• 주의사항: 동영상은 제외되며 오직 사진(이미지)만 처리됩니다.

🪟 Windows SmartScreen 경고 시

마이크로소프트 공식 인증서 등록 전 배포 파일이므로 "Windows의 PC 보호" 푸른색 창이 나타날 수 있습니다.

1 창 왼쪽 상단의 [추가 정보] 텍스트를 클릭합니다.
2 하단에 나타나는 [실행] 버튼을 클릭하면 정상 실행됩니다.
🍎 macOS 보안 경고(확인되지 않은 개발자) 시

인터넷에서 다운로드한 앱이므로 "악성 소프트웨어가 있는지 확인할 수 없습니다" 경고가 뜰 수 있습니다.

1 앱 아이콘을 마우스 우클릭(또는 Control + 클릭) > [열기]를 누릅니다.
2 팝업창에서 다시 [열기]를 누르면 이후로는 클릭만으로 실행됩니다.

❓ 자주 묻는 질문 (FAQ)

Q. 사진이나 영상은 어디 폴더에 넣어야 하나요? (Windows / Mac)

• Windows: 내 PC > 문서 > 블로그자동화_데이터 > 블로그_카페_수동이미지 폴더나 다운로드(Downloads) 폴더에 넣으시면 됩니다. 구글 드라이브를 쓰실 경우 G:\내 드라이브\수련사진을 연결하세요.
• Mac: Finder > 문서 > 블로그자동화_데이터 > 블로그_카페_수동이미지 폴더나 다운로드(Downloads) 폴더를 사용하시면 됩니다.

Q. 블로그나 카페에는 왜 동영상이 안 올라가고 이미지만 되나요?

네이버 블로그 및 카페 스마트에디터는 동영상 업로드 시 네이버 비디오 트랜스코딩 서버 인코딩 대기 시간이 발생하여 자동화 프로세스가 멈추거나 세션이 튕길 위험이 큽니다. 따라서 100% 안전한 고화질 사진(JPG, PNG 등)만 지원합니다. 동영상과 사진을 동시에 올리시려면 [네이버 밴드] 기능을 이용하시면 완벽하게 자동 분할 등록됩니다.

Q. 감지모드(Watch Mode)는 스마트폰으로 어떻게 활용하면 제일 편한가요?

컴퓨터에 프로그램을 켜두고 [자동 감지 시작]을 눌러둔 뒤, 스마트폰의 구글 드라이브 앱을 엽니다. 수업이 끝난 후 해당 부(예: 3시부) 폴더에 찍은 사진과 영상을 올리기만 하면 끝납니다! 60초 후 컴퓨터가 스스로 알아서 AI 글을 작성하고 밴드에 영상과 사진을 순서대로 깔끔하게 올려줍니다.

Q. 시리얼 인증 번호는 어디서 받나요?

프로그램 사용권 및 시리얼 번호는 관리자에게 직접 문의하여 발급받으실 수 있습니다. 발급받으신 시리얼 키를 첫 화면에 입력하시면 즉시 정품 인증이 완료됩니다.

Q. 프로그램 업데이트는 어떻게 진행되나요?

새로운 기능이나 패치가 출시되면 프로그램 우측 상단에 [업데이트 확인] 버튼이 표시됩니다. 클릭 1번으로 최신 버전 다운로드와 재실행이 완료되며, 기존 설정과 시리얼 정보는 100% 안전하게 유지됩니다.

Q. 네이버 아이디 로그인 보안에 문제는 없나요?

라이온 마케팅 프로그램은 외부 서버로 아이디나 비밀번호를 절대 전송하지 않습니다. 관장님의 PC 로컬 크롬 브라우저 환경에서 직접 안전하게 실행됩니다.
